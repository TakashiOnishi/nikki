# 日記アプリ 仕様書

## アプリ概要

SNSではなく「自分の内側」に向き合うための日記アプリ。  
書くことを通じて感情・思考の傾向を可視化し、自己理解と気づきを深める。

**キーワード：** 内省 / 気づき / 俯瞰 / 継続

---

## ターゲットユーザー

- 自己理解を深めたい人
- 感情や思考の傾向を客観的に知りたい人
- メンタルヘルスに関心があるが、病院に行くほどではない人
- 日記を続けたいが三日坊主になりがちな人

---

### 🔜 次に実装（APIなしで実装可能）

#### ① 気分トラッカー（手動入力）
日記保存時に気分を1〜5のスコアで記録する。

```
今日の気分: 😞 😕 😐 🙂 😄
             1   2   3   4   5
```

#### ② 気分推移グラフ
気分スコアを時系列で折れ線グラフ表示する（Chart.js使用）。

```
気分スコア
5 |        ●
4 |    ●       ●
3 | ●      ●
2 |
  └─────────────→ 日付
```

#### ③ コーチング質問（書いた後に表示）
保存後、AIっぽい深掘り質問をランダムまたはルールベースで表示する。

```
💭 気づきの質問
「この出来事で、あなたが一番つらかったのは何ですか？」
「同じ状況で、あなたが望んでいた結果は何でしたか？」
```

#### ④ 書き続けスコア（ストリーク）
連続記入日数・総記入日数を表示する。

```
🔥 7日連続記入中
📝 累計 23日記入
```

### 🤖 将来実装（Claude / OpenAI API が必要）

#### ⑤ AI感情分析
日記本文をAIに送り、感情スコア・感情の種類・思考パターンを返す。

```
今日の分析
 感情: 不安(60%) 期待(30%) 喜び(10%)
 思考の傾向: 過度な一般化 / 白黒思考
 一言コメント: 「失敗を恐れているようですね」
```

#### ⑥ BIG5スコア推移
蓄積した日記からBIG5（開放性・誠実性・外向性・協調性・神経症的傾向）を推定・グラフ化する。

#### ⑦ AIコーチング対話
日記を書いた後、AIが文脈を踏まえてセラピーっぽい質問を返してくれる。

#### ⑧ 週次・月次サマリー
「今週のあなた」として感情傾向・キーワード・変化をAIがまとめる。

## データ構造

```json
{
  "id": 1747123456789,
  "date": "2026-05-15",
  "title": "今日のこと",
  "body": "今日は...",
  "tags": ["仕事", "気づき"],
  "mood": 4,
  "createdAt": "2026-05-15T10:30:00.000Z"
}
```

---

## プライバシー方針

- データはすべてブラウザ内（localStorage）に保存
- サーバーへの送信は行わない（AI機能追加時は要検討）
- 他のユーザーのデータとは完全に分離
